# QuantFolio 选股方法论规格（用户核心规则 · v1.0）

> 来源：用户 2026-08-07 提供的选股方法论（尾盘五步法 + 早盘七步法）。
> 状态：**P0 硬需求**。两大选股模块必须以本方法论为核心逻辑，PRD 中的通用指标筛选作为高级可选条件保留。
> 本文档是 PRD 的补充需求，架构师/工程师必须将下述规则参数化为默认策略模板，且允许用户在 UI 上调整阈值后另存为"我的策略"。

---

## 一、尾盘选股器：尾盘五步法（按顺序逐步过滤，漏斗式）

> 场景：14:30 后尾盘布局，隔夜持有。每一步都是**硬性过滤**，通过前一步才进入下一步，UI 展示每步过滤后的剩余数量（漏斗可视化）。

| 步骤 | 条件 | 精确规则（可编码） | 设计意图（用户原话提炼） |
|---|---|---|---|
| 1 | **当日涨幅 3%~5%** | `3.0 ≤ pct_chg ≤ 5.0` | 尾盘能保持强势是真强；<3% 没活动，>5% 位置太高隔夜易被套。3-5% 冲劲与缓冲兼备 |
| 2 | **换手率 5%~20%** | `5.0 ≤ turnover_rate ≤ 20.0` | 筹码充分交换次日才有爆发；>20% 警惕主力借热闹出货 |
| 3 | **流通市值 50亿~500亿** | `50亿 ≤ circ_mv ≤ 500亿` | 小盘（<50亿）易被控盘上蹿下跳；大盘（>500亿）资金撬不动；中盘是最佳"船型" |
| 4 | **成交量连续 3~5 日温和放大** | 最近连续 N 日（3≤N≤5）满足 `volume[t] > volume[t-1]`，即逐日递增如台阶 | 主力持续吸筹、慢慢布局的痕迹；地基打得越扎实，楼层越高 |
| 5 | **K线形态健康（多头 + 无套牢盘压力）** | ① 收盘价站上 MA5/MA10/MA20：`close > MA5 > MA10 > MA20`（多头排列）<br>② 上方无密集套牢盘：以"现价距近 60 日最高价的空间"近似——`(max(high,60d) - close) / close ≥ 8%`（上方至少留有 8% 开阔空间，阈值可配置） | 趋势向上有惯性；上方空间开阔冲高才不被砸 |

**评分（对通过全部 5 步的标的，0-100）**：
- 放量台阶数（3/4/5 日）得分：30 分，每多 1 日 +10
- 涨幅贴近 4%（区间中枢）得分：20 分，距离中枢越远越低
- 换手率贴近 12.5%（区间中枢）得分：15 分
- 多头排列完整度（站上 3 条均线满分）：20 分，缺 1 条 -7
- 上方空间（越大越好，封顶 15 分）：`min(15, 空间%×1.5)`
- 缺失值处理：因子缺失记 0 分并在 score_detail 标注"数据缺失"

**默认模板名**：`尾盘五步法（用户核心）`

## 二、早盘选股器：早盘七步法（按顺序逐步过滤）

> 场景：9:25-9:30 集合竞价后、开盘前选股，当日短线搏杀。同样漏斗式逐步过滤。

| 步骤 | 条件 | 精确规则（可编码） | 设计意图 |
|---|---|---|---|
| 1 | **集合竞价涨幅 60 强** | 按 `auction_pct`（竞价涨幅）降序取 Top60 锁定初选池 | 竞价数据最真实，先大范围精简全市场 |
| 2 | **量比靠前** | `volume_ratio` 降序排名，取 Top30（默认，可配）；或 `volume_ratio ≥ 1.5` | 量比靠前 = 主力早盘抢筹意愿强烈，剔除僵尸股 |
| 3 | **竞价涨幅 3%~5%** | `3.0 ≤ auction_pct ≤ 5.0` | 高开 <3% 做多乏力；>5% 诱多易回落被套；3-5% 是蓄势黄金区间 |
| 4 | **流通市值 < 10亿** | `circ_mv < 10亿`（小盘！与尾盘 50-500 亿相反） | 小盘筹码集中、拉升资金少、易冲涨停；百亿大盘短线难爆发 |
| 5 | **K线多头趋势低压力** | ① `close > MA5 > MA10 > MA20 > MA60`（多头排列，含 60 日线）<br>② 上方无密集套牢盘：`(max(high,60d) - close) / close ≥ 8%` | 站稳 5/10/20/60 均线、多头向上才有拉升空间 |
| 6 | **锚定市场主线（热点板块）** | `sector ∈ 热点主线集合`，主线默认：商业航天 / AI / 人形机器人 / 半导体 / 创新药（可配置多选）；仅取该板块**前排**（按第 2 步量比或第 1 步竞价涨幅排序取前列） | 脱离主线题材难大涨，只做风口前排 |
| 7 | **开盘首笔爆量** | `first_trade_volume / 过去5日均首笔成交量 ≥ 2.0`（首笔量比 ≥2，默认，可配） | 首笔成交是主力真实操盘信号，直线抢筹才符合 |

> 注：第 7 步依赖开盘后首笔成交数据，种子数据中由派生数据提供 `first_trade_vol_ratio`；若某标的该字段缺失，标记"开盘数据待更新"，默认不通过（或按配置降级）。

**评分（对通过全部 7 步的标的，0-100）**：
- 量比排名分位（Top1% 满分）：25 分
- 竞价涨幅贴近 4%（区间中枢）：20 分
- 竞价量比（越高越好）：15 分
- 连板/涨停强度（有涨停记录 +5，连板数每 1 板 +5，封顶 20）：20 分
- 板块热度（主线第一档 15 分，第二档 10 分，第三档 5 分）：15 分
- 首笔量比（≥2 记 5 分，每 +1 加 1 分，封顶 5）：5 分
- 缺失值处理：同尾盘，记 0 分并标注

**默认模板名**：`早盘七步法（用户核心）`

## 三、两套方法论的对比矩阵（实现时注意差异）

| 维度 | 尾盘五步法 | 早盘七步法 |
|---|---|---|
| 涨幅口径 | **当日涨幅** 3%~5% | **竞价涨幅** 3%~5% |
| 换手率 | 5%~20%（有上下限） | 不设硬性换手限制（量比代替） |
| 流通盘 | **50亿~500亿**（中盘） | **<10亿**（小盘） |
| 量能 | 连续 3~5 日温和放大 | 量比靠前 + 开盘首笔爆量 |
| 均线 | MA5/MA10/MA20 多头 | MA5/MA10/MA20/MA60 多头 |
| 题材 | 无硬性要求（形态优先） | 必须属于市场主线板块 |
| 买入时机 | 14:30 后尾盘 | 9:25-9:30 竞价后 |

## 四、UI 呈现要求

1. 两模块默认加载对应模板（`尾盘五步法` / `早盘七步法`），第一步即展开漏斗视图：`全市场 N 只 → 步骤1 X 只 → 步骤2 X 只 → … → 最终 N 只`，每步标注过滤原因统计（如"淘汰原因 Top3：涨幅不足 3% / 换手超 20% / 市值超 500 亿"）
2. 每只命中标的显示**命中的步骤标签**（如 `涨幅4.2%` `换手8.5%` `中盘180亿` `3日连量` `多头排列`）
3. 用户可调整各步阈值并另存为"我的策略"（存全量 conditions JSON）
4. 上方套牢盘压力提示：对每个候选显示"上方 60 日高点空间 X%"，空间不足的标灰显示
5. 早盘模块的"竞价涨幅排行榜 Top60"需提供独立的竞价榜视图（列表 + 量比 + 竞价量比）

## 五、实现提示（给架构师/工程师）

- 需要新增/强调的指标与字段：
  - `auction_pct`、`auction_vol_ratio`（竞价数据，种子派生，已列入 PRD D-07）
  - `volume_streak`（连续放量天数，由 daily_quotes.volume 序列计算）
  - `first_trade_vol_ratio`（首笔量比 = 当日首笔成交量 / 前5日首笔成交量均值）
  - `high_60d_distance_pct`（现价距 60 日最高价的空间百分比）
- 两套"逐步漏斗"是**有序管线**（pipeline），不是平级 AND 条件——架构上建议做成可配置的 `ScreeningPipeline`（steps 数组 + 每步 filter + 每步 label + 淘汰统计），与 PRD 的通用指标筛选器（尾盘 C-01~C-09）并行存在：用户五步法/七步法为默认管线，高级指标为叠加可选条件。
- 早盘第 4 步（<10亿小盘）与尾盘第 3 步（50-500亿中盘）阈值相反，属于设计意图，不得"统一"。
- 所有步骤阈值必须落在配置常量中（`config/screening-defaults.js`），允许用户覆盖并保存。
